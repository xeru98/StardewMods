# Max Forge Upgrades
## Version 1.0.0

This is a very lightweight mod that allows you to customize some behavior with weapons and the forge. 
It is intentionally very feature sparse.

## Configuration Options
- **Max Forge Upgrades**: Sets the maximum number of times a weapon can be upgraded at the forge. (Vanilla 3)
- **Max Forge Level Per Gem Type**: Sets the maximum number of times a weapon can be upgraded at the forge with a game of the same type. (Vanilla 3)
- **Base Upgrade Cost**: Sets the base number of cinder shards to upgrade a weapon. (Vanilla 10)
- **Upgrade Scaling Amount**: Sets the number of additional cinder shards required per level to upgrade. (Vanilla 5)
